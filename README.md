# Fabrice Spahn — Personal Website

## Über mich

Ich bin Fabrice, ein Designer mit Fokus auf durchdachte digitale Erlebnisse, visuelle Identitäten und Designsysteme. Neben meiner selbstständigen Arbeit bin ich Teil des Teams hinter White Risk, der führenden Schweizer App für Lawinenprävention und Skitourenplanung. Dort verantworte ich die visuelle Identität und das Designsystem und gestalte die User Experience mit.

## Über dieses Projekt

Diese Website ist mein persönliches Portfolio. Sie präsentiert ausgewählte Kunden, Auszeichnungen und Ausstellungen in einem minimalistischen, typografisch geprägten Layout. Das visuelle Zentrum bildet ein animiertes Video-Raster mit einer interaktiven Klickwelle. Die Bereiche About und Contact werden als überlagerte Inhaltsseiten geöffnet.

## Lokal starten

Im Projektordner einen lokalen Webserver starten:

```bash
python3 -m http.server 8000
```

Danach im Browser öffnen:

```text
http://localhost:8000
```

## Struktur

- `index.html` — Seiteninhalt und Navigation
- `styles.css` — Layout, Typografie und Animationen
- `script.js` — Video-Raster, Klickinteraktion und Navigation
- `assets/` — Schriften und Hintergrundvideo
- `agb.html` — AGB-Inhalt, aktuell in der Navigation ausgeblendet

Die Website verwendet keine externen JavaScript-Abhängigkeiten und kann als statische Website veröffentlicht werden.
